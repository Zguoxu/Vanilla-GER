## 先理解一条数据怎样流动

```text
含噪音频 → Whisper → 多条候选文字 → LLaMA + LoRA → 纠正后的文字
人工参考文本 → 训练时作为答案；评分时与模型输出比较
```

按 `plan.md`，本项目做 HyPoradise 方法在 VoiceBank-DEMAND 上的迁移实验。输出是文字。WER 是词错误率，越低通常越好：参考为 `hello world`、预测为 `hello` 时，漏了 1 个词，WER 为 1/2，即 50%。推理输入只包含音频或候选，参考答案由训练、评分步骤独立读取。

### 第一步：创建 ASR 专用环境

在云端终端执行：

```bash
cd /home/featurize/work/Vanilla-GER
```

### 第二步：安装并验收最小 ASR 依赖

以仓库已验证过的 Python 包版本为兼容起点，云端 CUDA 构建单独选择。PyTorch 官方提供 2.5.1 的 CUDA 12.1 安装组合，见[官方历史版本安装说明](https://pytorch.org/get-started/previous-versions/#v251)。这是待在本项目云端验收的候选配置。

```bash
python -m pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
python -m pip install numpy==1.26.4 scipy==1.13.1 soundfile==0.13.1 transformers==4.46.3 ffmpeg-python==0.2.0 more-itertools==10.5.0 tqdm==4.67.1 PyYAML==6.0.2
python -m pip install -e .
python -m pip check
python -c "import torch, torchaudio; print(torch.__version__, torchaudio.__version__, torch.version.cuda); print(torch.cuda.is_available()); print((torch.ones(2, 2, device='cuda') @ torch.ones(2, 2, device='cuda')).cpu())"
```

验收：`pip check` 无冲突，CUDA 为 True，矩阵结果为全 2。`ffmpeg-python` 是 Python 接口，FFmpeg 可执行程序由第一步安装。Mac 的 `conda-osx-arm64.explicit.txt` 限定 macOS ARM64，Linux 使用本节独立环境。

后续已补充 `environment-cloud-asr.yml` 和 `requirements/cloud-asr.txt`，可以按 README 一次性重建 ASR 环境。`scripts/check_env.py` 也已支持将未安装的可选训练依赖记录为 `null`，最小 ASR 环境可运行该脚本保存环境报告；完整训练环境仍需另行安装、测试并保存依赖快照。
